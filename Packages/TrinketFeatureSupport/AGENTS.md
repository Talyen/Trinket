# TrinketFeatureSupport-local guide

Keep reusable game presentation, accessibility IDs, artwork support, and pure
presentation models here. Do not add app routing, encounter orchestration, Battle
lifecycle, or save mutations. Never import `TrinketBattleFeature`, `TrinketAppState`,
or the app module.

Verify package behavior with `./Scripts/test-package.sh TrinketFeatureSupport`.
