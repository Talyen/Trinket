# TrinketDesignSystem-local guide

This package owns reusable SwiftUI chrome, materials, typography, and motion. It may depend on `TrinketCore` only—never app features, `BattleEngine`, or `TrinketContent`.

Follow the package README and use first-party SwiftUI/accessibility fallbacks. Run `./Scripts/test.sh style` and `./Scripts/test-package.sh TrinketDesignSystem`.
