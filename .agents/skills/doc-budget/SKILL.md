# Comment hygiene

Keep a comment only when it records a subtle business rule, balance rationale,
non-obvious algorithm, or safety invariant. Delete docstrings that restate the
signature, parameter-by-parameter echoes, and inline chatter like
`// Create a VStack`. Clear naming beats explanation.
